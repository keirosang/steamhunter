Probably Stolen 100-Rev13 热修复：中文文本回滚，Lou 储物柜炸人 Bug 已修

各位赛博打工人、黑店掌柜、以及蹲在折扣区等背刺的仓鼠党，这次《Probably Stolen - Cyberpunk Shopkeeper Sim》端上来的不是新地图、新角色，也不是平衡性大改，而是一份典型的维护型热修。别看标题只有“Hotfix”，里面有一条 Bug 相当要命：Lou 的储物柜计数一乱，玩家直接挨炸。官方这次把中文文本、储物柜逻辑和 Modding API 安全更新三件事一起摆上了桌，咱们逐条拆。

🎯 核心看点速览

  • 补丁性质：100-Rev13 Hotfix，维护型热修，不是大版本内容更新。
  • 中文文本：名称、物品、对话与 UI 文本恢复为此前版本。
  • 致命 Bug：Lou 储物柜物品计数错误导致玩家被炸，修复对现有存档生效。
  • Modding API：12 月 10 日合入重大安全更新，模组作者需提前检查文档并更新作品。

📌 重点深度解析

1. 中文文本回滚：先把熟悉的配方端回来

官方这次把中文名称、物品、对话与界面文本拉回了上一版。简单说，不是加新词，而是把玩家已经熟悉的表述搬回来。对老玩家来说，阅读成本会降；对新玩家来说，至少不会在商店界面里对着一堆陌生名词怀疑自己买错游戏。

这类文本层调整通常不会动存档数据，但如果你装了文本类 Mod，更新后最好先进游戏扫一眼 UI 和物品描述。别一上来就冲进货架区，结果发现储物柜名字变成了不认识的东西，然后被 Lou 的机制教做人。

2. Lou 储物柜 Bug：从“计数错误”到“玩家被炸”

官方说明很直白：Lou 的储物柜物品没有被正确计数，导致玩家被炸。这个 Bug 的黑色幽默在于，赛博朋克店主本来就游走在灰色地带，储物柜里多一件少一件都可能是要命的事；现在计数一乱，直接物理超度。

好消息是，修复覆盖现有存档，老档不用重开。但注意：修复的是计数逻辑，不是给你补发被炸掉的货或钱。如果你之前已经被炸得血本无归，想找回损失还得看自己有没有备份存档。

3. Modding API 安全更新：12 月 10 日前，Mod 作者别装死

官方计划在 12 月 10 日完整合入一次重大 Modding API 安全更新。模组作者要检查更新后的 API 文档，并在节点前更新自己的 Mod。对普通玩家来说，这意味着：如果你装了 Mod，尤其是涉及商店逻辑、物品数据、UI 的 Mod，12 月 10 日前后要留意兼容性。别一上线发现储物柜又炸了，然后怪 Lou。

💡 玩家实操与上手建议

  • 更新与验证：Steam 库中让游戏完成更新；如果中文文本或 UI 仍异常，先重启游戏，再验证文件完整性。
  • 老存档：Lou 储物柜修复对现有存档生效；进游戏后先检查储物柜计数与库存，重要档建议手动备份。
  • Mod 玩家：12 月 10 日前备份存档和 Mod 配置；关注 Modding API 文档与 Mod 作者更新；不兼容的先禁用，别硬顶。
  • 购买建议：这次是热修复，不是折扣或喜加一；想入坑先看商店页近期评价与配置需求，想等好价就加愿望单，别把热修当史低。

❓ 常见问题 FAQ

Q1：中文文本恢复为此前版本后，我的老存档会受影响吗？

A：这次主要是文本层调整，通常不会改动存档里的物品数据。若出现界面文本错乱，先重启并验证文件完整性；装 Mod 的话优先排查文本类 Mod。

Q2：Lou 储物柜 Bug 修复对现有存档生效吗？已经被炸的损失能找回吗？
