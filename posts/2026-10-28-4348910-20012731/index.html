赛博黑店Probably Stolen 1.0开张：首发九折与九大开局

店名都叫 Probably Stolen 了，进货渠道就别问太细。这款赛博朋克当铺模拟经营终于结束抢先体验，1.0正式版开张，首发直接给到 10% off。你可以从学徒、卖水商一路干到销赃人和枪匠，在债务、黑市和房东的夹缝里把生意做起来，最后反手把店铺买下来。

🎯 核心看点速览

  • 1.0正式发售，首发九折：Steam 直接 10% off；另有含官方原声带的 Supporter Edition，以及和《Graveyard Keeper 2》《ReStory》《Potion Craft》《Backpack Battles》《TCG Card Shop Simulator》等作品的捆绑包。买前先查库，别为重复内容二次买单。
  • 9种开局：学徒、卖水商、销赃人、枪匠、化学师、水培农夫、水产农夫、老鼠牧人、一无所有（Rock Bottom）。
  • 4档难度：从新手友好到超级硬核，还能和“一无所有”叠加，体验赛博版白手起家地狱开局。
  • 剧情收束：犯罪头目 Lou、Eleanor、Lun 警官和学员 Serpico 的线都有完整交代；通缉名单上的罪犯也有扩展背景，包括 Butcher。
  • 结局与统计：买下店铺成为真正房东，结算最赚钱的一单、存活天数、总资产和已获 perk。
  • 创意工坊与模组 API：支持 Steam Workshop、模组 API 和模组本地化。
  • 自动售货机：关店后还能夜间继续卖货，睡后收入安排上。
  • 新 perk、UI 大改、21项成就：以及简中、俄语、西班牙语、法语、德语、波兰语和日语支持。

📌 重点深度解析

1.0不是小补丁，是整店翻新

这次正式版把“开店—鉴定—讨价还价—应付检查—还债—买店”的循环补完整了。九种开局不是换个初始背包那么简单，卖水商、水培农夫偏稳，销赃人和化学师更灰，枪匠风险高但来钱快，老鼠牧人则属于有味道的赛道。四档难度给了新手缓冲，也给老油条上强度；如果你选 Rock Bottom 再叠最高难度，基本等于在赛博贫民窟用牙签撬保险柜。

剧情线和结局终于落地

Lou、Eleanor、Lun 警官、Serpico 的故事线在 1.0 收束，通缉犯背景也补了，包括 Butcher。最终目标很明确：把店从房东手里买下来。结算会给出最赚钱的一单、存活天数、总资产和 perk，适合截图发群里凡尔赛。

自动售货机与模组生态

自动售货机是这版很实在的改动：关店后继续卖，等于把离线收益塞进赛博小店。Steam Workshop、模组 API 和模组本地化支持则把长线生命力拉满。不过注意，Demo 已经退役，为 Demo 做的模组大概率不兼容正式版，别硬套。

Demo存档与旧模组提醒

官方说 Demo 存档可以继承，但强烈建议新开档，不然容易错过新增剧情线。我的建议很直接：除非你 Demo 里已经攒出感情，否则新开更省心。

💡 玩家实操与上手建议

  • 购买：Steam 搜 Probably Stolen，首发 10% off。想要原声带就上 Supporter Edition；有上述游戏的话先看捆绑包，捆绑包合集在这里，按需补缺。
  • 开档：新手先用普通难度+学徒/卖水商熟悉鉴定和讨价还价；想体验黑店味就销赃人或化学师；Rock Bottom 留给二周目。
  • 赚钱节奏：尽早铺自动售货机，关店也有流水；优先推 NPC 剧情，结局条件和长期收益都在这条线上。
  • 中文设置：正式版含官方简中，进游戏设置里切换即可。
  • 模组：先跑原版，确认版本后再上创意工坊；旧 Demo 模组别装，容易出幺蛾子。
  • 评价：开发组是小团队，玩几个小时后顺手给个 Steam 评价，比在群里发“下次一定”实在。
