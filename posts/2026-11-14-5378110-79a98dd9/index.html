💡 本篇导读：《One More Lawn》首个补丁 1.0.1 已推送，Demo 同步更新。本次几乎照着玩家反馈清单逐条修复：割草机边角下车卡死、没油困在角落、双显卡笔记本被分配到弱显卡、PS 手柄按键错位、音频断续、联机客人白打工不解锁关卡等问题全部处理。同时新增船上音箱、岛上油罐玩法、编辑器野草可割，以及两套新的编辑器素材。

《One More Lawn》1.0.1 补丁上线：告别下车卡死，笔记本帧率与联机进度双修

上线第一周，开发者把 Discord、论坛和邮箱里的反馈几乎逐条抄进了补丁说明。1.0.1 是这个割草模拟器的首个正式补丁，Demo 版本同步获得同样的修复内容——试玩版和正式版这次站在同一条起跑线上。

🎯 核心看点速览

  • 下车卡死终结：侧边没空间时，会自动在最近的空位把你放下车，那句 「No room to get off here」 正式成为历史。
  • 没油了可以徒手拖车：所有关卡通用，油桶再远也能把割草机拽回来，角落憋死成为过去式。
  • 双显卡笔记本帧率复活：正式版此前被分配到核显上跑，现在会主动向 Windows 申请高性能显卡。
  • PS 手柄按键归位：○ 不再让你跳车，R2 不再自动点烟；DualShock 4 与 DualSense 免开 Steam Input 也能正常识别。
  • 联机客人不再白打工：和房主一起把活干到 90%，下一关对你也解锁，不只房主独享。
  • 新玩法：船上装音箱、岛上复刻加油罐技巧、编辑器地图里的野草也能割了换钱。

📌 重点深度解析

下车与拖车：两个最劝退的死局被拆掉

割草模拟最尴尬的瞬间，莫过于机器贴着一排栅栏停下，人下不来，油也见底。1.0.1 直接把两件事一起解决：下车判定改为寻找最近的可用空位，哪怕侧面被挡，也会把你放在能站的地方；油箱空了且油桶在半个地图外时，可以徒手拖着割草机走，任何关卡都生效。对喜欢把地图边角割到 100% 的强迫症玩家来说，这两条等于把心态保护机制焊死了。

双显卡笔记本：终于不吃核显的亏

有一批玩家反馈 Demo 里能跑 90 帧，买正式版却只剩 20 帧——原因是正式版被系统分配到了性能较弱的那块显卡上。补丁后游戏会主动向 Windows 请求高性能 GPU。这类问题在轻薄本与游戏本混用双显卡的机器上相当常见，属于典型的「配置没问题但跑得像 PPT」。

手柄与音频：小毛病，大体验

PS 手柄玩家此前的痛点很具体：想点烟结果跳下车，想下车结果点烟。现在 Circle 与 R2 的映射不再打架，DualShock 4 和 DualSense 不依赖 Steam Input 也能工作。同时，割草时声音断续、爆音的 PC 也拿到了修复，低帧率下乱甩甚至消失的割草高度杆一并归位。

联机进度共享：开黑终于是两个人的事

以前加入好友房间，活是一起干的，关卡是房主一个人解锁的。现在只要你们合力把当前任务推到 90%，下一关对客人同样开放。配合这次新增的船上音箱，联机割草的氛围组配置已经算是齐活了。

其他修复清单（挑要紧的说）

  • 棚屋、栅栏等刷漆木结构在部分显卡上不再闪烁。
  • 手里拿着草袋上割草机，手不会再保持「悬空拎袋」的诡异姿势。
  • 标题界面与暂停菜单重新显示版本号。
  • 创意工坊地图里，满袋草现在能丢进 Chiquito 招牌旁的箱子卖掉，不再弹开退货。
  • 渡轮、码头、桥上的草袋读档后不再凭空消失。
  • 地图编辑器：从 Chiquito 买的六罐装终于能正常放进自制地图、高尔夫球场与岛屿；婚礼帐篷落地、施工护栏翻转、装饰舞池不再浮空。
  • 修复岛屿加载时的一个报错。

新增内容：音箱、野草与两套编辑器素材

  • 船上音箱：按 E 把 Chiquito 的音箱放到任意船只上，它会跟着船走并继续放歌，联机可用。
  • 油罐技巧登陆岛屿：往婚礼的燃气烤炉上倒油，或者把油罐留在炉上再后退，玩法与本体一致，联机同样有效。
  • 野草可割：编辑器地图里的野生草现在能割进袋子换钱，但不计入任务完成百分比——刷钱可以，冲进度别指望。
  • 地图编辑器新增两套素材：「Elvira 带烧烤的屋子」自带完整院落与整套烧烤装备，木炭、报纸、肉、夹子以及那罐油都在；「带 DJ 的舞池」则是婚礼同款，音乐、灯光、激光、烟雾和火焰一应俱全。

💡 玩家实操与上手建议

  1. 更新方式：Steam 库中等待自动排队更新即可；若版本号没变，右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性后再启动。Demo 版本需要单独更新，别只更了本体。
  2. 笔记本玩家请手动确认一次：Windows 设置 → 系统 → 屏幕 → 显示卡，找到游戏主程序，手动指定「高性能」。系统有时会记住旧的分配结果，补丁给了请求权，但用户层的设置也要跟上。同时插电、关掉省电模式，帧率表现会稳得多。
  3. 联机开黑：客人想解锁下一关，关键是同一局内把当前任务推到 90% 以上，摸鱼到 89% 是拿不到进度的。
  4. 创意工坊地图卖草：满袋草不要放在地上发呆，直接朝 Chiquito 招牌旁的箱子扔过去，命中即结算。
  5. 编辑器玩家：野草是刷钱工具而非进度工具，设计关卡时可以用来做「经济区」；新出的带烧烤屋子与带 DJ 舞池建议先各摆一个测试联网同步效果。

❓ 常见问题 FAQ

Q1：1.0.1 需要手动下载吗？Demo 会不会一起更新？ A：正常情况下 Steam 会自动推送，重启客户端即可。Demo 是独立条目，需要单独更新才能拿到同样的修复内容，别只更了正式版就去测老问题。

Q2：更新后笔记本还是只有二十来帧怎么办？ A：先在 Windows 的「显示卡」设置里手动把游戏指定为高性能 GPU，再确认电源计划为高性能并插电运行。若依旧异常，验证一次文件完整性，排除旧配置文件残留。

Q3：联机时客人解锁下一关的条件到底是什么？ A：与房主在同一局内共同把当前任务完成度做到 90% 及以上，下一关会同时对客人解锁。注意是同一局进度，中途退出或换房重开都不算。

Q4：编辑器里的野草能用来冲 100% 完成度吗？ A：不能。野草只填袋、只换钱，不计入完成百分比，用来做刷钱区或装饰性草坪正合适。
