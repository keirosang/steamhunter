《Scam With Your Friends》0.1.99更新：云语音识别上线，俄语语音优化

✍️ SteamHunter · 📅 2026-11-09 09:48 · ⏱️ 约 6 分钟阅读 · 📝 2570 字
🛒 访问 Steam 商店 ⚡ 客户端直达
💡 本篇导读：Steam 联机骗术模拟《Scam With Your Friends》推送 0.1.99 更新：云端 Whisper Large 语音识别顶替退休的 Gladia 正式上线，本地识别漏词时可自动兜底，葡语玩家终于不用对着麦克风干瞪眼，俄语转写与 MOSS 语音也同步优化。玩法侧，IP 定位来电者开始按性格与对话节奏决定挂断时机，地图追踪支持全球任意落点，Lock Trace 一键锁定更显眼。联机部分修复了 Streamer Mode 下队友屏幕消失、屏幕采集崩溃以及卡在椅子里等问题。

🎯 核心看点速览

  • 云端语音识别正式启用：Whisper Large Cloud 接替退休的 Gladia，在官方认证的 Steam 大厅里可手动开启，通话语音会送往 DeepInfra 转写，专门解决本地模型漏词的问题，葡语改善最明显。
  • 俄语使用体验补齐：电话转写默认隐藏重音符号，MOSS 语音播放同样跳过这些标记，但 ё、й 这类字母原样保留。
  • 骗术玩法更灵活：IP Geolocation 来电者会根据性格、对话走向和你对读数的解释来决定何时挂断，语气更有说服力，就能多争取一点追踪时间。
  • 地图追踪机会更多：点城市、点历史读数即可落点，整个可见地球（连海面）都能猜，Lock Trace 按钮也放大了。
  • 联机与录像修复：Streamer Mode 与家庭友好模式下队友的电脑屏幕不再神秘消失，BanditCam 保护通话中的自动录像，顺带修好了卡在椅子上动不了的经典 bug。

📌 重点深度解析

一、云端语音接班，本地识别漏词有备选

开发组这次把通话语音这一整条链路理顺了。老玩家熟悉的 Gladia 选项正式退休，接棒的是 Whisper Large Cloud——只在官方认证的 Steam 大厅里可选。它的定位很清醒：不替代本地模型，而是作为本地识别漏词时的额外识别手段。尤其是葡语，本地模型经常听一半漏一半，切到云端之后整段通话的识别稳定性提升非常直观。

代价是隐私：选了云端，通话语音就会被送到 DeepInfra 做转写。开发组把这件事写在明面上，两个入口（设置 > Speech，以及电话上的麦克风面板）都给了完整说明，选不选在你。

低配设备的玩家也有照顾：Whisper 可以退到更轻的 Base 模型，Whisper Small 与 Whisper Base 还能单独勾选 Always use CPU，把显卡留给游戏本体。备用切换逻辑也做得比较细——本地识别突然停止工作、云端又可用时，游戏会提示你把上一句再说一遍，这次临时切换不会覆盖你原本保存的选择；万一云端转写也失败，还能重试、直接打字，或者换一个服务商。

另外几处优化偏向稳定性：Qwen 语音在启动、结束通话或离开通话时的清理更干净；重新排序语音模型时，正在进行的下载不会中断；设置页也会区分「临时内存压力」和「硬件本身不兼容」这两种情况，避免玩家误判自己的配置。

二、俄语语音链路补齐

俄语电话转写默认隐藏重音符号，阅读体验干净不少；MOSS 语音播放同样跳过这些标记，但 ё、й 这类关键字母原样保留，不会把词读歪。顺带一提，One Pac 的开场白改了，现在他打来会先自报家门——很小的细节，但对刚进坑的新人友好很多。

三、骗术与 Kolkata OS：来电者也开始考虑对话情况

IP Geolocation 这类来电者不再死守固定脚本挂电话。现在他们的挂断时机取决于各自性格、对话走向，以及你怎么解释手里那堆读数。换句话说，解释得像模像样，就能多拖延一会儿，给队友争取追踪窗口——这是本次更新里对玩法影响最大的一条。

追踪环节的交互也顺手了：点城市、点历史读数都会直接把猜测落在对应位置；整个可见地球都能点，包括海面；Lock Trace 按钮放大，最后一步不容易点偏。电话记录里高亮的验证码，点一下就会复制并更可靠地填进对应 App 的输入框——哪怕来电者还在说话也不耽误。

桌面端的小改进同样实用：应用右键菜单里新增 Open to，Scamazon 里的信使图标更显眼；Kolkata OS 的图片占用内存下降，内存吃紧时会延迟加载新图；Mr. Curry 的解锁播报不再长篇大论，改成一句针对具体骗术或工具的短说明，接电话时耳朵清净多了。

四、联机、录像与办公室里的杂项修复

  • Streamer Mode 与家庭友好模式下，队友在世界里的电脑屏幕现在保持可见。以前主播一开这俩模式，队友屏幕就直接消失，配合起来一脸茫然。
  • 针对 Windows 屏幕采集在显存分配失败时的崩溃加了防护，屏幕流关闭或玩家掉线时的清理也更干净。
  • BanditCam 会在通话中以及挂断后片段收尾期间保护自动录像；开启录像时，通话窗口之外依然可以手动录制。
  • 修好了离开或快速重开桌上电脑后「卡在椅子里、既不能看也不能动」的老问题。
  • 还有一个自带黑色幽默的修复：手动尿尿现在能浇灭显示器上的病毒火。是的，这很本作。

💡 玩家实操与上手建议

  1. 先把版本更到 0.1.99：Steam 库中右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性，确保语音相关的新组件完整下载，避免「设置里找不到 Whisper」的尴尬。
  2. 语音方案按配置分档：显卡吃紧就选 Whisper Base 并勾上 Always use CPU；网络稳定、追求识别率的队伍可以直接开 Whisper Large Cloud，尤其队里有葡语玩家时收益最大。
  3. 把隐私选项说清楚：云端转写会把通话语音发到 DeepInfra，开黑前跟队友交代一句，介意的话全员统一用本地模型，别一边云端一边本地互相等识别。
  4. 开黑分工更清晰：嘴皮子利索的负责拖延来电者，另一个人专门盯地图追踪和验证码回填。新版来电者挂断时机随机性更强，拖时间的人越会解释读数，追踪位就越从容。
  5. 主播与录屏党：更新后再开 Streamer Mode，队友屏幕会正常显示；BanditCam 会自动保护通话期间的录像素材，重要的手动片段记得在通话窗口外补录。
  6. 遇到语音异常别急着重装：本地识别断了但云端可用时，游戏会提示重说上一句；云端失败可以直接打字应付当前通话，先把客户哄住，再回设置里换服务商。

❓ 常见问题 FAQ

Q1：开启云端语音后，我的通话内容会被传到哪？ A：选择 Whisper Large Cloud 后，通话语音会发送至 DeepInfra 进行转写，这是开发组在设置页明确写出的说明。如果你比较在意隐私，就留在本地识别模型上，代价是复杂语种或嘈杂环境下漏词概率更高。

Q2：电脑配置一般，语音经常识别不到位怎么办？ A：把识别模型降到 Whisper Base，并为 Whisper Small / Base 单独开启 Always use CPU，把显卡资源让给游戏本体；同时留意设置页提示，区分是临时内存压力还是硬件不兼容，前者关掉几个后台程序往往就能缓解。

Q3：更新里提到的 Russia Access，是解锁俄区还是加了俄语？ A：从本次更新内容看，主要是俄语语音链路完善——电话转写与 MOSS 语音播放都会处理重音符号，同时保留 ё、й 等字母，属于语言与语音层面的优化。

Q4：开了 Streamer Mode，队友屏幕还是黑的？ A：这次已经修复了该问题，其他玩家在世界里的电脑屏幕在 Streamer Mode 与家庭友好模式下都会保持可见。如果仍然异常，先验证游戏文件完整性，确认版本确为 0.1.99，再排查是否是屏幕采集崩溃防护触发后的临时状态。
