Grandparadox V1.1.1 更新：文字聊天、服务器浏览器与房间权限开关一次到位

独立开发者 jbg 给刚上架不久的 Grandparadox 推了首个生活质量补丁 V1.1.1。按作者自己的说法，这些都是等 Valve 审核期间攒下来的小心思——不是什么内容大版本，但每一条都冲着「让人能顺利联机、能看懂怎么玩」去的。对一款体量不大、靠联机与重复游玩撑时长的作品来说，这种补丁的价值往往比多两张地图更直接。

🎯 核心看点速览

  • 新增「how to play」玩法说明：终于不用靠猜或翻社区帖来搞懂基础操作。
  • 新增服务器浏览器：可浏览公开房间与好友房间，找局不再靠邀请码口口相传。
  • 新增房间可见性开关：私密 / 仅好友 / 公开三档，邀请码规则各不相同。
  • 新增局内文字聊天：配套一个非常基础的「冒犯性词汇」过滤。
  • 修复 UI 溢出：部分界面元素会压到屏幕底部之外并被拉伸的问题已处理。
  • 标题界面显示版本号：反馈问题时能直接报版本，省去扯皮。

📌 重点深度解析

服务器浏览器 + 三档房间权限，联机体验的分水岭

这次最实质的改动是联机入口的补齐。过去想凑一局，基本只能靠外部渠道发邀请码；现在有了服务器浏览器，公开房和好友房都能直接列出来，进房效率完全是两个量级。

权限设计值得单独说，因为三档的规则并不一样，容易踩坑：

房间类型 加入方式
公开（public） 邀请码，或从服务器浏览器直接进
仅好友（friends-only） 邀请码，或通过 Steam 好友关系加入
私密（private） 仅限邀请码

注意最后一条：私密房不会出现在任何列表里，只认邀请码。想开小圈子局、又不想被路人乱入的，认准这一档；想拉 Steam 好友但懒得发码的，用「仅好友」最省事。

文字聊天与词汇过滤：能沟通了，但别期待太多

联机游戏没有文字 Chat 是硬伤，这次补上了。配套的「offensive terms」过滤作者自己都形容为「非常基础」——意思很明确：别指望它能挡住所有东西，它只是兜底，不是 moderation 系统。开黑时该有的基本礼貌还是得靠自己。

UI 修复与版本号：小改动，长期收益

「部分 UI 会重叠并拉伸到屏幕底部之外」这个 bug 属于典型的忍一忍能玩、但每次看到都烦的类型。修复本身不炫技，不过对于分辨率或窗口比例比较刁钻的玩家来说，可能正是之前排版错乱的元凶。标题界面加版本号则是为后续反馈与排查铺路——作者已经在文末提到，后面还排着无障碍相关与玩法模式（gamemode）的补丁，以及更多、更难的成就，用来提升重复游玩价值。

💡 玩家实操与上手建议

更新与进房

  1. Steam 库中确认 Grandparadox 已完成更新，启动后先在标题界面核对版本号是否为 V1.1.1，便于后续反馈。
  2. 首次进入先看一遍新加的「how to play」，比在局内试错省时间。
  3. 找野局：直接开服务器浏览器筛公开房；和朋友玩：开「仅好友」房，让 Steam 好友列表进；小圈子局：开私密房，只发邀请码。
  4. 进房后确认文字聊天可用，若输入无效，先检查是否被过滤规则误伤，换一种措辞再试。

开黑避坑

  • 私密房别指望别人能在列表里刷到，务必把邀请码发到群或私聊。
  • 想要稳定固定队伍，优先「仅好友」，避免公开房被随机玩家反复打断节奏。
  • 界面若仍有元素压边或被裁切，记录分辨率与窗口模式一并反馈给作者，这类问题定位成本很低。

配置与购买建议

本作体量不大，配置压力有限，重点放在窗口模式与分辨率匹配上，避免非标准比例触发排版问题。尚未入手的玩家可以先看商店页与社区评价再决定，把它当作一款适合与熟人固定开黑的小品级作品来预期，体验会更贴合实际。

❓ 常见问题 FAQ

Q1：V1.1.1 之后，私密房还能被服务器浏览器搜到吗？

不能。私密房只认邀请码，不会出现在公开或好友列表中；想让好友自己找进来，请把房间设为「仅好友」。

Q2：文字聊天发了没反应，是被过滤了吗？

有可能。当前过滤规则非常基础，遇到疑似误判换个表达方式重试即可；这不代表聊天功能失效。

Q3：这次更新有没有新增玩法模式或成就？

没有。V1.1.1 属于生活质量补丁，聚焦说明文档、联机入口、房间权限、文字聊天与 UI 修复。作者已表示后续会推进无障碍与 gamemode 相关补丁，并追加更多、更难的成就。

Q4：界面还是被屏幕底部裁掉了怎么办？

先确认版本号是 V1.1.1，再尝试切换窗口模式或调整到标准分辨率比例；若问题复现，带上分辨率、窗口模式和截图反馈给作者，定位会快很多。
