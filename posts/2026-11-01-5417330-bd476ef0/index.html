《Sort Sort Yokai》1.1.3更新：双显卡与鼠标手感修复

✍️ SteamHunter · 📅 2026-11-01 12:27 · ⏱️ 约 3 分钟阅读 · 📝 1460 字
🛒 访问 Steam 商店 ⚡ 客户端直达
💡 本篇导读：《Sort Sort Yokai》1.1.3 补丁主打笔记本体验修复：双显卡机型现在会正确调用独显，告别核显拖后腿；帧率不足时自动降画质并提示，手动设置则会锁定；低帧率下快速甩鼠标不再丢输入，新增 Raw input 开关让视角更跟手，bug 报告也会附带帧率数据。

各位整理癖和妖怪收集党注意，《Sort Sort Yokai》悄咪咪推了 1.1.3 补丁。这次没有新妖怪、没有新关卡，主打一个“把笔记本玩家从核显地狱里捞出来”。如果你之前用轻薄本玩，转视角像在搅水泥、菜单点半天没反应，那这波更新就是冲着你来的。

🎯 核心看点速览

  • 双显卡笔记本强制走独显：游戏会在 Windows 图形设置里把自己设为“高性能”，不再让核显摸鱼。
  • 帧率不够，自动降档：跑不动当前画质时会自动下调并提示；你手动选的档位会牢牢锁定。
  • 低帧率下快速甩鼠标不再丢输入：转身、点菜单都更跟手。
  • 新增 Raw input 开关：Settings > Mouse > Raw input，默认开启，鼠标视角更直接。
  • bug 报告自带帧率数据：方便开发者定位性能问题，反馈卡顿终于有据可查。

📌 重点深度解析

这次 1.1.3 属于典型的“体验型补丁”，不背刺老玩家，也不动平衡性，纯修底层手感。

1. 双显卡调度：让独显干正事

很多笔记本既有独显又有核显，Windows 默认可能让游戏跑在省电的核显上。结果就是画面能看，但转视角有延迟、菜单像开了 0.5 倍速。更新后游戏会自动把自己登记为“高性能”应用，优先调用独显。你也可以在 Windows 的图形设置里手动改回来，适合想省电的掌机/轻薄本用户。

2. 动态画质：跑不动就降，但听你的

如果当前画质设置超出机器能力，游戏会自动降低一档并提示你。注意，一旦你在 Settings 里手动选了画质，它就会保持你的选择，不再自作主张。对喜欢锁死帧数上限、追求稳定观感的老哥来说，这个逻辑很舒服。

3. 鼠标输入修复：低帧率也不吞输入

低帧率下快速甩鼠标，最怕输入被吞——明明甩了 180 度，角色还在看墙。1.1.3 修复了快速鼠标转向在低帧率下丢失的问题。配合新增的 Raw input 选项（默认开启），视角会更接近“手到眼到”，适合需要快速整理、频繁点选的玩法。

4. 诊断信息升级

现在提交 bug 报告会附带帧率信息。别小看这个，性能问题最难复现，有了 FPS 数据，开发者能更快判断是显卡调度、画质档位还是别的原因。

💡 玩家实操与上手建议

  • 更新后先查显卡：进游戏前打开 Windows 设置 > 系统 > 屏幕 > 显示卡，确认《Sort Sort Yokai》被设为“高性能”。NVIDIA 控制面板或 AMD 软件里也可以强制指定独显。
  • 不想被自动降画质：直接在 Settings 里手动选档位，游戏会保持你的选择。
  • Raw input 怎么选：默认开启更直接；如果你习惯系统鼠标加速，或者用特殊外设，建议开/关各试一局，选跟手的那个。
  • 笔记本优化三连：插电、Windows 电源模式切“高性能”、关掉后台占资源的浏览器和录屏软件。
  • 遇到卡顿别硬扛：用游戏内反馈提交 bug 报告，帧率数据会一起带上，比单纯说“很卡”有用得多。
  • 购买建议：这次是免费更新，已入库的玩家直接更新即可；还没入坑的可以先加愿望单，等史低或免费周末再下手。

❓ 常见问题 FAQ

Q1：更新后我的双显卡笔记本还是用核显，怎么办？

A：先确认 Windows 图形设置里游戏是否为“高性能”，再到 NVIDIA/AMD 控制面板里手动指定独显。部分品牌机还有自己的性能模式软件，记得切到性能模式。

Q2：自动降画质太激进，能关掉吗？

A：可以。在 Settings 里手动选择画质档位后，游戏会保持你的选择，不再自动下调。

Q3：Raw input 要不要开？

A：默认开启，鼠标视角更直接。若你习惯系统鼠标加速或使用特殊外设，建议开关对比一下，手感差异一局就能试出来。

Q4：bug 报告里的帧率信息会泄露隐私吗？

A：从更新说明看，只是附带帧率数据用于定位性能问题，不涉及账号或个人信息。正常提交反馈即可。
