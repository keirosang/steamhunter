🎮 关于 Steam 蒸汽猎手 (Hugo + GitHub Pages)

欢迎来到 Steam 蒸汽猎手独立情报站！

本站是一个完全独立部署于 GitHub Pages 的现代化静态游戏情报专栏，致力于为广大 PC 游戏玩家提供极速、纯净、高质量的 Steam 情报资讯。

⚡ 架构与运作模式

  1. 🤖 独立全自动采集程序

    • 采用纯 Python 编写的独立采集引擎（完全解耦于外部项目）；
    • 定时巡检 Steam 官方资讯与最新重大特惠/限免情报；
    • 具备严格的时效校验与数据库增量去重机制，杜绝重复发布与历史旧闻。

  2. 🧠 LLM 智能玩家主理人润色

    • 对接 OpenAI / DeepSeek / 通义千问等主流大语言模型；
    • 杜绝生硬机翻，自动转译并重塑为地道、幽默具有玩家主理人风格的中文精品长文；
    • 自动生成核心亮点速览、深度剖析、上手实战指南与实用 FAQ。

  3. 📦 自动化 Hugo 构建与 GitHub Pages 部署

    • 自动生成标准化 Hugo Markdown 文章与防盗链静态图床；
    • 本地构建与 GitHub Actions 双轨支持，一键推送至 GitHub 极速上线。
