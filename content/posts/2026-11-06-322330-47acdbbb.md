各位饥荒老农、洞穴包工头、月岛钓鱼佬注意了，科雷又端上了一盘热气腾腾的热修复。Hotfix 762113 没有新 Boss，也没有新皮肤，但它修的都是能让人拍桌子的“祖传小毛病”。下面我按影响面给你拆开看。

## 🎯 核心看点速览

- **地图界面新增音效**：打开地图终于不是静音 PPT 了。
- **深渊蠕虫波次修复**：开了选项却永远不来的地下“快递”恢复派送。
- **月风暴生态修复**：月盲乌鸦与畸形鸟不再犯傻。
- **荧光蟹刷新与设置崩溃修复**：黄昏刷新恢复，世界设置调“Little”不再闪退。
- **猪人无限硬直修复**：疯猪被攻击后不再永久罚站。
- **美人鱼重复生成与装备移植修复**：读档不再多刷美人鱼，缝合怪类不再把装备“穿”到奇怪生物身上。
- **清道夫换肤隐形修复**：水球和漂浮物不再突然隐身。
- **Linux 黑 UI 与多人切分片卡加载修复**：Linux 玩家和洞穴联机党都能少受点气。

## 📌 重点深度解析

### 1. 地图界面终于有声音了

这次更新给地图界面补上了音效。别小看这一点，长期开图、找路、标记资源的玩家会明显感觉到操作反馈更完整。以前点开地图像在看一张会动的静音表格，现在至少知道自己在“操作”地图，而不是对着一张纸发呆。

### 2. 深渊蠕虫波次修复：地下基地的警报器回来了

官方修掉了“即使开启深渊蠕虫波次也永远不来”的 Bug。对洞穴建家党来说，这不是小事：蠕虫波次既是威胁，也是稳定的怪物肉、腺体和掉落来源。修复后，开了选项的存档要重新检查防线，别还按“反正不来”的旧思路裸奔。

### 3. 月风暴生态修复：月盲乌鸦与畸形鸟不再犯傻

月风暴事件期间，月盲乌鸦和畸形鸟的行为异常已被修复。喜欢在月风暴期间刷材料、跑图或做月岛相关内容的玩家，可以重新观察它们的行动逻辑。简单说，科雷把这两位的“脑回路”接回去了。

### 4. 荧光蟹与黄昏刷新：海洋生态小补丁

荧光蟹在黄昏不刷新的问题已经修复，同时修掉了世界设置中把荧光蟹调成“Little”时可能出现的崩溃。海钓佬、海上建家党和喜欢夜间赶海的玩家，这次可以正常期待黄昏时段的海面动静。

### 5. 猪人无限硬直修复：战斗手感回归正常

疯猪被攻击后总是被无限硬直的问题修了。以前有些玩家打疯猪像在打木桩，现在它会更正常地还手。开黑时别再用旧套路站桩输出，尤其带新人的时候，提醒一句“猪会动了”能少翻一次车。

### 6. 美人鱼重复生成与装备移植：存档清洁工松口气

这次还修了两个很影响存档整洁度的问题：每次重载额外生成美人鱼，以及缝合法兰肯猪、美人鱼、吸血鬼兔会“移植”到带装备的生物身上。前者会让存档越来越乱，后者会出现装备穿在奇怪生物身上的诡异画面。修复后，长期存档和联机服务器都能少一点玄学。

### 7. 清道夫换肤隐形：水球和漂浮物不再隐身

使用清道夫换肤后，水球会隐形，水面上的一些漂浮物也会在换肤后隐形。这个 Bug 对喜欢装修、换皮肤和打水球的玩家很烦。现在官方已经修复，换完皮肤记得检查一眼，确认没有“看不见的道具”留在场上。

### 8. Linux 黑 UI 与多人切分片卡加载

Linux 下部分 UI 元素变黑的问题修了；多个玩家同时切换分片导致卡在加载循环的问题也修了。对洞穴联机服务器来说，后者尤其重要。虽然修复了，但服务器管理员还是建议在更新后重启主世界和洞穴分片，避免旧进程残留。

## 💡 玩家实操与上手建议

- **更新方法**：Steam 库中确认《饥荒联机版》已更新到最新版本；联机服务器要重启，主世界和洞穴分片都要重启，别只重启一半。
- **开黑避坑**：虽然多人同时切分片卡加载已修复，但建议队友错开跳洞、跳世界，减少服务器瞬时压力。
- **洞穴建家党**：确认世界设置里深渊蠕虫波次是否开启；如果开启，尽快补围墙、检查照明和战斗站位。
- **疯猪战斗**：别再默认疯猪会被无限连到死，带新人的话提前说清楚，免得队友还按老版本节奏贴脸输出。
- **海洋玩家**：黄昏时段可以重新留意荧光蟹；使用清道夫换肤后，检查水球和漂浮物是否正常显示。
- **Linux 玩家**：更新后如果 UI 仍异常，先验证游戏文件完整性，再检查是否有 UI Mod 冲突。
- **购买建议**：本次是免费热修复，不需要额外买 DLC；想入坑的玩家可以等本体折扣，皮肤和角色礼包按喜好补，不影响这次修复内容。

## ❓ 常见问题 FAQ

**Q1：Hotfix 762113 需要重新开档吗？**

不需要。本次是热修复，正常存档兼容；但联机服务器必须重启，主世界和洞穴分片都要更新到同一版本。

**Q2：为什么更新后深渊蠕虫还是不来？**

先确认世界设置里深渊蠕虫波次已开启，再确认洞穴分片已经重启。如果装了修改生成规则的 Mod，优先排查 Mod 冲突。

**Q3：清道夫换肤后水球和漂浮物还是隐形怎么办？**

官方已修复该问题。更新后如果仍然遇到，先验证游戏文件完整性，再禁用相关皮肤或 UI Mod 排查；联机服务器也要确认已重启。
