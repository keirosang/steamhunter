## 🎯 核心看点速览

各位电话诈骗模拟器爱好者注意了，《Scam With Your Friends》悄悄推上了 **0.1.92** 补丁。别看版本号只跳了一格，这次动的可都是玩家天天要摸的东西：

- **新增 Gladia 语音识别**：在「设置 > 语音」里填入你自己的 API Key 即可启用，音频直连 Gladia，费用走你自己的账号，Key 只留在本机，官方不碰。
- **Mr Curry 点评大改**：老板点评的台词更贴合你实际录下的通话内容，玩家与来电者的对话区分更清楚，还会根据你的「忽悠」是否成功给出不同反应。
- **点评支持多语言**：字幕与语音解说会按房主选择的语言生成，共享回放时保持同一语言。
- **内置网页浏览器被彻底移除**：商店条目、保存的网页快捷方式、浏览器音频控制、隐私提示一并删干净，病毒里的浏览器劫持和老板点评里的浏览历史吐槽也随之消失，「Jesus Loves You」成就同步下架。
- **办公室场景修复**：三楼道具与等候桌碰撞对齐、玻璃分格独立可碎、玻璃透明度与裂纹表现、楼层光照刷新、角色与服装亮度统一等一整串修补。
- **手机输入 Bug 修复**：发完消息或结束语音输入后，文本框有时「装死」不接受继续打字的问题已解决。

一句话总结：**加了一个正经的语音识别方案，砍掉了一个不该存在的浏览器，顺便把老板的嘴修得更毒了。**

## 📌 重点深度解析

### 一、Gladia 语音识别：自带 Key，隐私优先

这次最硬核的改动是语音输入方案。你可以在 **设置 > 语音** 中找到 Gladia 相关开关与配置项，填入自己申请的 API Key 后启用。官方明确说明：语音音频直接发往 Gladia，用量计费在你的 Gladia 账户上，密钥保存在本地电脑，不经过游戏服务器。

配套的体验也补齐了：

- 新增 Gladia 配置引导控件；
- 缺 Key、连接失败等情况会有更清楚的错误提示，不再让你对着黑屏猜；
- 语音设置里加了语言支持提示气泡，选哪个模型、支持哪些语种一目了然；
- 选择性 **Qwen3 TTS** 现在优先为中文、日文、俄文使用 Qwen。

对国内玩家来说，最后这条挺关键——中文语音合成的自然度会有明显提升，念你那些「话术」时不容易出戏。

### 二、Mr Curry 的点评重做：骂人也要骂得有理有据

老板点评系统这次是重头戏：

1. **台词更贴通话内容**：玩笑和吐槽会针对你实际录下的通话，不再是万能模板。
2. **对话归属更清晰**：字幕能区分哪句是玩家说的、哪句是来电者说的，复盘时不会看串。
3. **按成败给反应**：你这一单「话术」是成了还是翻车，点评反应会跟着变，代入感拉满。
4. **多语言生成**：字幕与口播按房主所选语言生成，共享回放时保持该语言，开黑队友不会听到一嘴混杂语。
5. **家庭友好模式同步升级**：点评字幕与解说更干净，在生成解说之前就会过滤掉不合适的性相关内容。

另外还顺手修了几个实际影响体验的点：

- 老板在「新应用公告」之后生成的收尾发言现在会保留，不会说完就蒸发；
- 开除播报改用生成的判定结果，逻辑更一致；
- 对格式错误、内容不完整、被限流的点评响应加强了恢复处理，减少「没声音」「没字幕」的尴尬；
- 每日点评收益与排名改为按**计入配额的金额**结算，而不是看个人钱包的浮动，刷分党可以收手了。

### 三、浏览器之死：砍得好

内置网页浏览器这次被连根拔起，包括它在商店里的条目、保存的网页快捷方式、浏览器音频控制和隐私提示。连带效果是：病毒不再劫持你的浏览器，老板点评里也不会再吐槽你的浏览历史。

屏幕隐私逻辑也做了简化：**家庭友好模式**与**主播模式**继续负责隐藏其他玩家的电脑屏幕与屏幕共享，功能边界更清楚，不再和浏览器那一摊搅在一起。

### 四、办公室场景修补：玻璃终于能好好碎了

- 三楼道具与等候桌的碰撞对齐修正，隐形残留碰撞障碍清掉，不再走着走着被空气墙拦住；
- 三楼办公室玻璃修复：不同窗格开口拥有尺寸正确、可独立击碎的玻璃片，碰撞也匹配；
- 玻璃透明度与裂纹表现优化，破损后依然看得穿，裂痕更局部、更真实；
- 办公室光照更新，覆盖上层楼层、半墙和道具，楼层加载时光照刷新更顺畅；
- 角色、服装、配饰亮度统一，Mr Curry 的西装和尖叫脸染色都更稳定；
- 员工预览、玩家头像、老板摄像头画面的光照改善；
- 便利贴贴图干扰光照的问题修好。

## 💡 玩家实操与上手建议

**1. 想用 Gladia 语音？先备好 Key**

进入 **设置 > 语音**，按引导填入 Gladia API Key。注意这是自带账户制，用量计费在你自己的 Gladia 账号上，建议先去 Gladia 后台确认额度和计费方式，再决定是否长期开启。如果你只是偶尔开黑，用默认语音方案也完全够用。

**2. 中文玩家建议优先试 Qwen3 TTS**

选择性 Qwen3 TTS 现在优先为中文、日文、俄文启用 Qwen，中文语音的自然度更稳。设置里新增的语言支持气泡记得点开看一眼，别选了个不支持中文的模型然后怀疑人生。

**3. 主播与家庭场景直接用模式开关**

直播或和家人同屏时，打开 **主播模式 / 家庭友好模式**，其他玩家的屏幕与屏幕共享会被隐藏，老板点评里的敏感内容也会在生成前被过滤。这次更新后逻辑更干净，可以放心开着播。

**4. 老存档与旧快捷方式**

浏览器被移除后，之前保存的网页快捷方式不再生效，属于正常现象，别以为是坏档。游戏内商店里的浏览器条目也一并下架了。

**5. 开黑避坑小贴士**

- 语音输入结束后如果文本框没反应——这个 Bug 已在 0.1.92 修复，务必更新到最新版；
- 老板点评偶尔没声音，多半是响应被限流，新版本已加强恢复处理，仍遇到可以重开一次点评；
- 三楼玻璃现在是分格独立可碎，撞窗逃跑时注意别只看整面墙，裂的是哪一格就是哪一格。

**6. 更新方式**

Steam 库中右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性，或直接等客户端自动推送 0.1.92。

## ❓ 常见问题 FAQ

**Q1：Gladia 语音识别是免费的吗？我的 Key 安全吗？**

不是官方统一买单。你需要自备 Gladia API Key，语音音频直接发往 Gladia，用量计费在你自己的 Gladia 账户上。密钥保存在你本地电脑，不会上传到游戏服务器，官方也不会代你保管。用不用完全可选，不开也能正常玩。

**Q2：内置浏览器没了，会影响游戏进度或成就吗？**

不会。浏览器相关的商店条目、保存的快捷方式、音频控制与隐私提示都被移除，病毒不再劫持浏览器，老板点评也不再吐槽浏览历史。与之绑定的「Jesus Loves You」成就同步下架，属于官方主动调整，不影响其他成就的解锁。

**Q3：老板点评没声音、没字幕怎么办？**

0.1.92 已经针对格式错误、内容不完整和被限流的响应加强了恢复处理，并保留了公告后的收尾发言。如果仍然遇到，先确认设置里的语言与语音选项是否匹配，再重开一次点评；另外家庭友好模式会过滤部分内容，字幕与解说看起来「变短」属于正常表现。

**Q4：每日点评收益和排名怎么算的？**

新版本改为按**计入配额的金额**结算，而不是看个人钱包的增减。也就是说，把钱老老实实交进配额才算数，靠钱包来回倒腾刷排名已经行不通了。
