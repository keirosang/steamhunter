结论先说：这次 **v1.0.0 (7)** 不是堆内容的大版本，而是把前期经济、Deadeye 强度和快进手感这三颗最容易硌脚的问题逐个处理了一遍。对正在推进关卡的玩家来说，第 1、2 关的升级货币变多，等于官方给你发了一笔“开局启动资金”；Deadeye 被削弱则意味着那套“一枪一个”的省事打法要重新算账。

## 🎯 核心看点速览

- **前期经济松绑**：第 1、2 关提供的升级货币增加，开局运气差带来的强烈挫败感会缓一口气。
- **Deadeye 攻击下调**：具体数值官方没给，但方向很明确——别把它当万能答案。
- **快进速度永久记忆**：下一局、下次启动都保留你上次设的速度，刷子狂喜。
- **修复一批手感与视觉问题**：单位转身错位、第 6 关裂隙在 Judgment Waves 期间颜色异常、暂停时点击 Controls 菜单外仍会触发其他条目等。
- **杂项修复**：小毛病一并处理，整体稳定性更好。

## 📌 重点深度解析

### 1. 第 1、2 关货币加量：把“开局穷”往后挪

Slotbound 这类构筑爬关游戏，最难受的不是后期打不过，而是前两关穷到只能捡垃圾，核心组件迟迟不来，直接被滚雪球。这次官方把第 1、2 关的升级货币产出抬高，等于把“开局穷”这个坎往后挪了一截。

实际影响很直接：

- 新手更容易在前两关凑出能打的雏形，不至于第一关就进入“看广告复活”的心态；
- 老手可以更早投资经济类或核心输出类升级，滚雪球启动更快；
- 一些依赖特定升级才成型的流派，前期成型概率变高，不用把把赌命。

需要说明边界：官方只给了“更多”这个方向，没有公布具体百分比或固定增量。想知道涨了多少，最靠谱的办法是开一局新 Run，在第 1、2 关分别记录升级界面货币数，和更新前自己的截图对比。

### 2. Deadeye 削弱：狙击流从“答案”变回“选项”

Deadeye 这次是攻击降低。官方没写具体砍了多少，所以别急着把整套 Build 判死刑，也别继续无脑堆。它原本的定位大概率是单体高伤、远程点杀，攻击下调后，处理精英和 Boss 的阈值会变高，你需要补别的输出来填缺口。

我的建议是：

- 先进一局，看 Deadeye 面板攻击和实际跳字，确认削弱幅度；
- 如果原本靠它一枪清掉某类单位，现在打不死，就要么补易伤/增伤，要么换目标优先级；
- 别把全部经济押在一个单位上，混合输出更稳。

### 3. 快进速度保留：体验层最香的一刀

『Your Fast Forward speed is now kept for the next run and the next launch.』这句话看着不起眼，实际是这次热修里最提升日常体验的改动。以前每开一局、甚至每次启动都要重新调速度，刷起来像每次出门都要重新系鞋带。现在设置一次，后面继承。

注意一个小细节：如果你习惯在不同阶段切不同速度，继承的是你上次离开时的速度。进局先瞄一眼当前倍速，别在关键波次用错档位。

### 4. 修复项里的隐藏痛点

- **单位转身跳位**：转身时单位位置抖动/错位，会影响近战卡位和碰撞判断，修掉之后站位更可信。
- **第 6 关裂隙颜色**：Judgment Waves 期间裂隙保持普通颜色，视觉提示不明显，容易误判节奏；现在颜色恢复正常，战场信息更清楚。
- **暂停菜单点击穿透**：暂停时点 Controls 菜单外面会触发其他条目，手滑党福音，少一次误改设置。
- **杂项修复**：不展开，但这类小修通常能减少偶发卡顿和奇怪交互。

## 💡 玩家实操与上手建议

1. **更新方式**：Steam 库中等待自动更新，或重启 Steam 客户端触发；更新后进游戏确认版本号。
2. **当前 Run 要不要重开**：稳妥起见，热修后重启游戏，新开一局体验新数值。进行中的 Run 是否实时套用改动，官方没细说；想准确对比就开新局。
3. **前期货币怎么花**：第 1、2 关多出来的钱，优先补核心输出或经济引擎，别散给一堆用不上的小升级。
4. **Deadeye 流先测阈值**：更新后先打一局，记录它还能不能一击处理关键单位；不能就补伤害或换思路。
5. **快进设置一次到位**：进游戏先把 Fast Forward 调到你最舒服的档位，之后跨局、跨启动都会记住。
6. **遇到异常先验证文件**：Steam 库右键游戏 → 属性 → 已安装文件 → 验证完整性，排除更新残留。

**Q1：这次 v1.0.0 (7) 热修需要手动下载吗？**
