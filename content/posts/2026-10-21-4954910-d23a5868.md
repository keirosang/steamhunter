# 《Scam With Your Friends》0.1.83 更新详解：成就、云存档与防炸档三件套

各位老哥，我是你们的老朋友，Steam 专栏主理人。今天聊聊《Scam With Your Friends》刚推的 0.1.83 补丁。别看版本号只跳了一小格，内容量相当扎实：26 项 Steam 成就、云存档、全新存档系统，还有一堆联机与语音体验优化。对成就党、开黑党、以及被“炸档”背刺过的玩家来说，这波都值得更新。

## 🎯 核心看点速览

- **26 项 Steam 成就上线**：覆盖骗术、进度、办公室整活和其他里程碑，成就计数器跨会话保留，Steam 暂时确认不了也会排队补发。
- **Steam 云存档实装**：进度、外观、声望、检查点、永久应用购买都能云同步。
- **新存档系统**：带备份和更安全的写入方式，旧版 v82 的设置、购买和检查点会自动导入。
- **设置内新增 RESET SAVE**：有二次确认，会清空进度、外观和永久购买，但保留设备本地设置。
- **联机体验优化**：公共大厅显示当前模式和天数，国家标签更清楚；Join by Code 说明更明确，Steam 好友按钮直接开当前大厅邀请。
- **语音与性能修复**：Boss 复盘视频播不了或卡住时，自动切到带静帧和文本的音频回放；Qwen3 TTS 支持 6GB 显存显卡。

## 📌 重点深度解析

### 1. 26 项成就：成就党狂喜，但别急着刷

这次一口气塞进 26 项 Steam 成就，覆盖面很广：骗术操作、进度推进、办公室整活、以及其他里程碑。官方特别提到，成就计数器会在会话之间保留，就算 Steam 一时半会儿确认不了，已获得的成就也会排队，等能确认时补上。换句话说，不用担心“明明达成了却没跳杯”的尴尬——至少它给你留了后路。

### 2. 云存档 + 新存档系统：这次真防炸档

云存档覆盖进度、外观、声望、检查点和永久应用购买，换电脑、重装系统、临时去网吧开黑都更稳。更关键的是新存档系统：带备份、写入更安全，旧版 v82 的设置、购买和检查点会自动导入。官方还减少了重复磁盘写入，改成后台保存，既降低炸档概率，也少让硬盘背锅。

注意，图形、麦克风、语言、控制、音量和个人 API key 仍然保存在每台电脑本地，不会跟着云存档跑。这个设计挺合理：网吧麦和家里麦本来就不是一个音量。

### 3. RESET SAVE：手滑党福音，也是手滑党噩梦

设置里新增了确认过的 RESET SAVE。它会清空进度、外观和永久应用购买，然后把你送回主菜单，但保留设备设置。也就是说，重置的是游戏进度，不是你的画面和按键。官方加了确认步骤，算是给“手滑党”上了个保险；但还是要提醒一句：点之前看清楚，别把几十小时进度一键送走。

### 4. 联机体验：大厅信息更清楚，拉人更顺手

公共大厅列表现在会显示当前模式和天数，国家标签和提示也更清楚。Join by Code 增加了更明确的说明，复制大厅代码后还会告诉你该怎么分享。Steam Friends 按钮现在直接打开当前大厅的邀请对话框，玩家列表里的好友按钮也能打开好友资料；Steam 覆盖层不可用时，会走网页资料页。开黑拉人这一步，终于不用再像解谜。

另外，玩家名字里的格式标签不会再干扰头顶名字和声望显示，新增的默认来电者会带 NEW 徽章出现在 Daily Callers 靠前位置；更新已有来电者的语音或头像不会误标新。自动回复漏掉括号或大小写不一致时，来电代码处理也更稳。

### 5. 语音与性能：6GB 显存也能跑 Qwen3 TTS

Boss 复盘视频播不了或卡住时，游戏会切到音频回放，带静帧和文本记录；切换时还会把失败的视频播放静音，避免声音打架。Qwen3 TTS 现在支持符合条件的 6GB 显存显卡，同时保留其他硬件要求。Whisper 在繁忙帧中完成识别时，不会再误报超时；Qwen 清理逻辑也改进了，避免被阻塞的音频连接拖住取消或退出。

### 6. 一堆细节修复

- 玩家坐在座位上时不会再被撞成布娃娃，布娃娃快捷键也会尊重电脑输入捕获。
- 桌面布局、浏览器快捷方式、点击器进度、外观和永久应用所有权的保存更稳。
- 存档提示和大厅代码确认在设置界面上方的可见性更好。
- 玩家名字格式标签、头顶名字、声望显示之间的冲突修了。

## 💡 玩家实操与上手建议

1. **更新后先进设置看云存档状态**：第一次同步可能要多等几秒，别急着开游戏。换电脑前，确认上一台机器已经完成云同步。
2. **开黑前统一版本号**：0.1.83 和旧版混用容易遇到大厅显示或加入问题，建议全员更新后再拉人。
3. **重置存档前先备份**：虽然新系统有备份，但 RESET SAVE 会清空进度、外观和永久购买。手滑没有后悔药，确认框看清楚再点。
4. **6GB 显存玩家可以试试 Qwen3 TTS**：先把显卡驱动更到较新版本，再进语音设置里测试；如果出现卡顿，优先降画质或关闭其他占显存的程序。
5. **视频复盘卡住别急**：等它自动切音频回放；如果一直不切，退出重进当前检查点，通常比硬等更省时间。

## ❓ 常见问题 FAQ

**Q1：成就不跳杯怎么办？**
A：先确认 Steam 在线并保持游戏运行一会儿。官方说已获得的成就会排队，Steam 暂时确认不了也不会丢；如果长时间不补，重启 Steam 和游戏再试。

**Q2：云存档会覆盖本地存档吗？换电脑后设置还在吗？**
A：云存档同步进度、外观、声望、检查点和永久应用购买。图形、麦克风、语言、控制、音量和个人 API key 仍保存在每台电脑本地，所以换电脑后这些设备相关设置需要重新调。

**Q3：RESET SAVE 会删除什么？能恢复吗？**
A：它会清空进度、外观和永久应用购买，然后返回主菜单，但保留设备设置。官方没有承诺一键恢复，点之前务必看清确认提示；重要进度建议先等云存档同步完成。

**Q4：6GB 显存显卡能开 Qwen3 TTS 吗？**
A：这次更新支持符合条件的 6GB 显存显卡，但其他硬件要求仍然保留。实际体验受驱动、画质和后台占用影响，建议先测试再长期开启。
