- **Campaign Hub走格子**：打PvP或VS AI比赛推进格数，走到第10格可拿随机技能代币、随机位置代币、50 eFootball Coins、12,000 Exp与25,000 GP
- **活动任务**：参与指定Events与eFootball™ League，完成全部目标可拿随机Booster Token、随机技能代币、30,000 Exp与30,000 GP

## 📌 重点深度解析

### 1. 每日POTW抽卡券：最值得关注的福利

这次活动的核心亮点是“**Free Chance Deal Everyday**”。活动期间只要登录，就能在登录奖励里领到1张“POTW: Worldwide 5 Nov '26” Chance Deal。说白了就是**每天免费抽一次当周POTW卡池**，对零氪和微氪玩家来说，这是补强阵容、碰运气抽当红球员的好机会。

需要特别注意：登录奖励**每天北京时间10:00刷新**，当天不领不会累积到第二天。活动整整覆盖7天，理论上最多能拿7张券，建议设个提醒，别因为时差或忘记上线而错过。

### 2. Campaign Hub走格子：踢比赛就能拿Coins

Campaign Hub的玩法很直接：在指定期间内打**PvP或VS AI比赛**，推进一定格数就能领奖励。走到第10格的奖励如下：

| 奖励内容 | 数量 |
| --- | --- |
| Random Skill Token（随机技能代币） | ×1 |
| Random Position Token（随机位置代币） | ×1 |
| eFootball™ Coins | ×50 |
| Exp. | 12,000 |
| GP | 25,000 |

这里有个容易踩的坑：**Exhibition（友谊赛）、Training（训练）、Skill Up（技能提升）模式的进度不算数**。想推进度，老老实实打PvP或VS AI。对于不想被真人玩家“上强度”的朋友，VS AI就是最稳妥的选择，既能刷格数，又能顺手完成其他任务。

### 3. Campaign Objectives：任务党别漏了Booster Token

活动任务要求玩家参与符合条件的Events和eFootball™ League，完成全部目标后可以拿到：

- Random Booster Token ×1
- Random Skill Token ×1
- 30,000 Exp
- 30,000 GP

奖励里的**随机Booster Token**对阵容养成挺关键，尤其是想给核心球员补强特性的时候。建议从Home界面点进Objectives逐一查看完成条件，别只盯着比赛，有些目标需要你分别参加Events和League才能全部点亮。

### 4. European Clubs特别活动：打AI攒积分

同期开放的European Clubs特别活动，规则是**和AI对战并收集Event Points**来换奖励。适合想稳定刷资源、又不想在PvP里被“军训”的玩家。活动时间和主活动一致，可以跟Campaign Hub的VS AI进度一起刷，效率更高。

1. **每天上线先领券**：登录奖励每天北京时间10:00刷新，建议固定在上午或晚上上线一次，先领Chance Deal再踢球。
2. **优先把Campaign Hub推到第10格**：50 Coins、25,000 GP和12,000 Exp都挺实用，越早拿完越安心。用VS AI刷进度最省心，别去Exhibition模式白忙活。
3. **PvP和VS AI交替刷**：Campaign Hub只认PvP和VS AI，打AI稳定推进度，打PvP则能顺手完成部分活动目标，两边都不耽误。
