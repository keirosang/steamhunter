# Windowed Realms 1.0 正式上线：海盗海岸、PvP 决斗与每周挑战全解析

各位老哥，今天有款小体量但脑洞不小的作品正式摘掉「抢先体验」的帽子了——**Windowed Realms 1.0 现已登陆 Steam**。开发组在公告里感谢了试玩 Demo 的玩家与提前试玩的内容创作者，并把从上一版 Demo 到 1.0 的全部改动一次性摊开讲了个明白。我把这份更新日志从头到尾捋了一遍，挑出对中国玩家最实用的部分，咱们一条条看。

![](/static/windowed-realms-1-0-keyart.jpg)

## 🎯 核心看点速览

- **两大新领域**：Corsair Coast（海盗海岸）敌人坐船骑海马登陆，Mistvale（迷雾谷）侏儒塔顶射击、塔倒即近身肉搏。
- **出征前的新岛屿**：每次远征都有独立小岛，先排队伍再出发；远征窗口重做，敌方列表与己方队伍分列两侧。
- **英雄装备可视化**：国王、剑士、骑士、狂战士会实际显示手持的武器与盾牌，双持单位双手齐挥，空手单位赤膊上阵。
- **采集者独立养成**：原「棋子」更名 Gatherers，每个单位独立等级（上限 100）与技能树，洞穴生物会和采集者并肩作战。
- **每周挑战回归**：每周一刷新，全员同一套开局 + 特殊规则（巨型敌人、开局即暗影生物等），带当期队伍冲榜，首轮还给卡尘。
- **实时 PvP**：自带单位打三局两胜，战斗节奏比远征更长，独立排行榜，可在设置里随时开关。
- **体验细节**：Esc 关窗、B 开 Builds、L 开 Album、窗口常驻岛屿之上并记住所在显示器，OBS 每个游戏窗口只显示一条采集源。

## 📌 重点深度解析

### 海盗海岸与迷雾谷：两种完全不同的压迫感

**Corsair Coast** 的设计思路是「立体登陆」。敌人不再只从地面推进，而是乘船、骑海马从海面扑上你的岛；水中的海盗塔会同时发射炮弹和鱼——是的，鱼也是投射物。更关键的是机制联动：**骑乘坐骑或站在塔上的敌人伤害更高**，这意味着你不能只盯着血条，还得优先拆掉它们的「载具」。

**Mistvale** 则把「制高点」玩成了双刃剑。侏儒在塔顶远程输出，你把塔打塌，他们落地转而近战——听起来是削弱，实际上是换了一种更黏人的打法。清塔的时机需要斟酌：早拆会让近战单位提前贴脸，晚拆则持续挨射。

另外每次远征开局前都会给一座四面环水的新岛屿，用于编排出战队伍。这个改动看似只是 UI，实则把「先看敌人阵容、再配队」的策略前置了，远征窗口的左右分栏正是为此服务。

![](/static/windowed-realms-expedition-window.jpg)

### 武器、盾牌与双持：数值之外的视觉反馈

1.0 给四名英雄加了实打实的武器模型：

- **King**：剑或长矛
- **Swordsman**：长矛或斧
- **Knight**：剑或斧
- **Berserker**：双斧同挥

规则也很直白：**双手各持一把武器的单位会同时用两把攻击**，完全没武器的单位则用拳头打。配合下面这条改动——武器技能现在随单位攻击力成长——意味着「堆攻击」不再只影响平砍，技能伤害也会跟着水涨船高。换句话说，武器与技能的词条搭配值得重新算一遍。

### 装备提示重构：这次终于能好好读词条了

物品悬浮提示被整个重做：悬停在高亮术语上能看到二级说明，**等提示框的环形进度走满即可锁定**，方便静下心慢慢读；换装时立刻显示每项属性的增减幅度；物品还会标注来源。对于喜欢在配装界面反复琢磨的老哥，这几条改动比加十个新道具都实在。

### 采集者与岛屿：从背景板变成养成线

原先只负责捡资源的「棋子」正式更名为 **Gatherers**，每人拥有独立等级（最高 100）与独立技能树。配合「建得越多、岛屿越大、现在四面环水」的设定，以及洞穴生物会与采集者并肩作战——这块内容已经从边角料升级成了可持续投入的养成副线。别忘了，1.0 还顺手修了采集者卡在岛屿角落的毛病。

### 相册与每周挑战：长期留存的两根柱子

**Album（相册）** 现在能查看每种生物的暗影版本，套组页会标明哪些职业适用该套组、哪些技能能吃到加成，收集党有得忙了。

**每周挑战**每周一开启新一周，所有人同一套 run、附加一条特殊规则。你可以带着「当前的队伍原样」出发——注意，不是给你一套满配，而是考验你现有 box 的深度——尽力推远并冲击周榜。**每周首轮还会给卡尘**，这算是给白嫖党留的固定收入。

### PvP：可开关的异步焦虑解药

用自己的单位打实时三局两胜，战斗时长比远征更长，有独立排行榜。最重要的一点：**这是可选内容，设置里随时开关**。不想被人打扰的纯 PvE 玩家完全可以当它不存在，这点设计挺体面。

### 界面与修复

- Esc 关闭当前窗口；**B** 打开 Builds，**L** 打开 Album。
- 窗口始终浮于岛屿之上，并记住上次所在的显示器——多屏玩家狂喜。
- 直播的老哥注意：OBS 里每个游戏窗口只显示一条条目，采集源不再刷屏。
- 设置里可直接提交 bug 与建议；教程被缩短，主菜单新增制作人员名单。
- 修复项包括：窗口加载中打开不再卡死、退出全屏不再画面变形、采集者不再卡岛屿角落。

## 💡 玩家实操与上手建议

1. **先跑一遍缩短后的教程**，再进新岛屿编排队伍。新远征窗口的左右分栏信息量大，开局前务必看一眼敌方构成，尤其是海盗海岸有没有骑乘单位与水中塔。
2. **海盗海岸优先拆载具**：骑乘与塔上敌人有伤害加成，先清坐骑和塔，比硬堆前排划算。迷雾谷则要权衡清塔时机，别让近战侏儒过早贴身。
3. **配装时善用提示锁定**：环形进度走满锁定提示，再逐条对比换装前后的属性增减；武器技能吃攻击力成长，攻击词条的性价比比以往更高。
4. **采集者别荒废**：独立等级上限 100，早投早收益，岛屿扩建与洞穴生物协同是长期战力的一部分。
5. **每周一记得打首轮**：同一套 run 拼的是你对现有阵容的理解，首轮卡尘是稳赚不赔的固定收益。
6. **PvP 按需开启**：想练手就去打三局两胜，嫌累在设置里关掉即可，不影响 PvE 进度。
7. **快捷键记牢**：Esc 关窗、B 建设、L 相册；多显示器玩家可放心拖窗口，位置会被记住。

## ❓ 常见问题 FAQ

**Q1：1.0 是免费更新吗？之前玩过 Demo，存档能接着用吗？**
A：本次是正式版发布，公告梳理的是「自上一版 Demo 以来」的全部改动，包含新领域、PvP、每周挑战与界面重构。Demo 与正式版的内容差异较大，建议按新版教程重新起步；具体存档继承情况以商店页面与游戏内说明为准。

**Q2：PvP 是强制的吗？不打会不会影响进度？**
A：不强制。PvP 为实时三局两胜、独立排行榜，可在设置中随时开启或关闭，不影响远征与每周挑战的推进。

**Q3：每周挑战用什么队伍？必须重新练一套吗？**
A：不需要。每周挑战直接用你「当前的队伍原样」出征，全员同一套 run 加一条特殊规则，比拼的是推进深度；每周首轮还会额外给卡尘奖励。

**Q4：采集者（Gatherers）和以前的棋子有什么区别？**
A：更名之外，每个采集者拥有独立等级（最高 100）与独立技能树，洞穴生物会与其并肩作战，岛屿也会随建设扩大并四面环水，属于实打实的养成线升级。
