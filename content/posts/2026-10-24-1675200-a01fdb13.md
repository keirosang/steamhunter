## 🎯 核心看点速览

- **全量推送**：SteamOS 3.9.5 已面向所有用户开放，包含自 3.8 稳定版以来的全部改动，不是只给测试通道的“尝鲜包”。
- **桌面模式大版本**：Plasma 6.4.3 升级到 6.7.3，Arch Linux 底层同步更新，Linux 内核来到 7.2。
- **掌机痛点修复**：Steam Deck 无音频播放时的空闲功耗优化，隐藏 WiFi 首次连接失败修复，帧率限制器与 VRR 兼容性修复。
- **游戏兼容性**：修复《艾尔登法环》《黑暗之魂3》在 Panther Lake Intel CPU 上无法运行的问题，Legion Go 2 获得初版亮度控制。
- **Valve 全家桶**：改进 Steam Frame 无线适配器支持，修复 Steam Machine 相关显示、固件更新与串流问题。
- **开发者注意**：WiFi 后端默认切到 wpa_supplicant，休眠初版支持已进内核，但 Game Mode UI 未开放，Steam Deck 暂未启用。

## 📌 重点深度解析

### 桌面模式不再是“赠品”

这次最显眼的变化，是桌面模式从 Plasma 6.4.3 直接跳到 6.7.3。对只把 Steam Deck 当游戏机的人来说，这可能只是“哦，桌面变好看了”；但对折腾党、模拟器玩家和接显示器办公的老哥来说，窗口管理、缩放、多屏和桌面组件的体验都会更现代。再加上 Arch 底层与 Linux 7.2 内核同步更新，属于那种平时不显山露水、真出问题时能救命的底子工程。

### 续航与连接：小修小补，但刀刀到肉

Steam Deck 在没有音频播放时的空闲功耗得到优化，说人话就是：待机、看网页、挂下载时更省电一点。别指望一更完续航多两小时，但蚊子腿也是肉。隐藏 WiFi 首次连接失败的 bug 也被修了，这个痛点谁用谁知道——尤其是公司网络、酒店网络和家里“我明明设了隐藏 SSID”的硬核玩家。

### 帧率限制器与 VRR：别再互相打架

更新修了开启 VRR 时 Disable Frame Limiter 开关不生效的问题，也修了某些外接显示器上帧率限制导致实际 FPS 低于预期的问题。掌机外接屏最怕什么？游戏里设 40 帧，屏幕给你跑 30 帧，帧生成时间还像过山车。这波修复对喜欢底座模式、便携屏开黑的玩家很实用。另外，游戏模式里误拖启动器窗口导致输入丢失的问题也修了，少一个“手柄突然失灵”的玄学。

### 兼容性修复：老游戏与 Intel 新平台

《艾尔登法环》和《黑暗之魂3》在 Panther Lake Intel CPU 上无法运行的问题被修复，这对新款 Intel 掌机或外接显卡坞用户是好消息。Legion Go 2 获得初版亮度控制，虽然只是“初版”，但总比在系统里摸黑调亮度强。还有《极限竞速：地平线6》在 Legion Go 2 上启动崩溃、《星球大战：银河赛车》休眠恢复性能问题、《飙酷车神：轰鸣盛典》GPU 错误等修复，属于“你未必全遇到，遇到一次就血压拉满”的补丁。

### 休眠：先别急着把充电器收起来

开发者日志里提到 Linux 内核加入初版休眠支持，还能中断休眠请求，并修了一堆驱动问题。但注意，Game Mode UI 还没开放，Steam Deck 上也因为驱动问题暂未启用。所以别看到“休眠”两个字就以为掌机要变 iPad，现阶段该插电插电，该休眠休眠，等 Valve 后续把坑填完再说。

## 💡 玩家实操与上手建议

- **更新方法**：稳定通道用户进入“设置 > 系统 > 软件更新”检查更新，更新前插上电源、留足存储空间，更新完重启一次再进游戏。
- **桌面模式检查**：升级到 Plasma 6.7.3 后，建议进桌面看看缩放、多屏和输入法是否正常；桌面锁屏默认仍是关闭的，想用可以在设置里手动开启。
- **WiFi 避坑**：隐藏网络首次连接已修复，如果还连不上，先删除旧配置重连，或进桌面模式用网络设置手动添加；开发者可关注默认后端已切到 wpa_supplicant。
- **帧率与 VRR**：外接屏玩家更新后重测帧率限制器和 VRR 组合，别一股脑把 TDP 拉满；如果帧数仍异常，先关 VRR 再对比。
- **老游戏与 Intel 平台**：《艾尔登法环》《黑暗之魂3》在 Panther Lake 上的启动问题已修，Intel 新机用户更新后先验证这两个“试金石”。
- **Legion Go 2 用户**：亮度控制是初版支持，别期待完美；遇到《地平线6》启动崩溃可以先更新系统再试。
- **休眠别急**：Game Mode 没有休眠 UI，Steam Deck 暂未启用，别拿它当主力省电方案。

## ❓ 常见问题 FAQ

**Q1：SteamOS 3.9.5 怎么更新？稳定通道能收到吗？**

A：可以。进入“设置 > 系统 > 软件更新”检查更新即可。更新前建议插电并预留空间，更新后重启一次，避免桌面模式和游戏模式状态不同步。

**Q2：桌面模式升级到 Plasma 6.7.3 后，锁屏和远程桌面有变化吗？**

A：桌面锁屏不再被设置项强行阻止，但仍然默认关闭，想用可以手动开。RDP 使用系统用户登录的问题也修了，远程折腾桌面更顺一点。

**Q3：休眠功能现在能在 Steam Deck 上用吗？**

A：暂时别抱太大希望。内核已有初版休眠支持，但 Game Mode UI 还没开放，Steam Deck 也因驱动问题未启用。现阶段把它当成开发者铺垫就好。

**Q4：隐藏 WiFi 还连不上怎么办？**

A：这次修复了首次连接失败，如果仍异常，删除旧网络配置重连，或进桌面模式手动添加；默认 WiFi 后端已切到 wpa_supplicant，兼容性取向更稳。
