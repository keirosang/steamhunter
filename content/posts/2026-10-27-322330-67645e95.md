各位在永恒领域里被饿死过十七次的老朋友们，我是你们的老主理人。科雷这次又悄悄推了个小热修——Hotfix 760178，补丁体积不大，但每一条都精准落在玩家的日常痛点上。别看它没有新角色、没有新生物，这种“小修小补”往往才最影响你今晚能不能活着看到第 30 天。

## 🎯 核心看点速览

| 改动方向 | 具体内容 |
| --- | --- |
| 活动玩法 | 猪王给糖时有概率改给南瓜炸弹；落叶堆产出糖果的概率上调 |
| 平台修复 | 修复 Mac 设备上运行游戏的问题 |
| 联机表现 | 修复客户端开启预测时，使用附魔女巫扫帚的动画异常 |
| 操作体验 | 落叶堆现在可以用动作键直接清扫 |
| 生态平衡 | 岩石龙虾在月岛洞窟、远古档案等酸雨区域不再被酸雨伤害 |
| 皮肤显示 | 国王科学机器被烧后不再隐形；蝎子手杖镶嵌宝石后在背包中正常显示 |
| 模组支持 | 专用服务器新增可选启动参数，允许模组读写 cluster 存档目录 |

一句话总结：**糖还是那颗糖，但今年的糖可能会炸。**

## 📌 重点深度解析

### 🎃 猪王的糖罐里，混进了雷

节日活动期间去找猪王讨糖，本来是最佛系的日常——递点小玩意，换一把糖果，顺手还能把猪人朋友哄开心。这次改动之后，猪王在发放糖果时有几率改塞给你一枚**南瓜炸弹**。

翻译成人话：你伸手接糖的那一瞬间，可能接到的是个会响的玩意儿。建议各位养成好习惯，拿到手先别急着往背包深处塞，更别在基地的箱子堆、火药库、队友的睡袋旁边试爆。真要验证成色，请移步空旷地带，或者干脆送给那个总抢你肉丸的队友当“礼物”。

### 🍂 落叶堆：从“碰运气”变成“常驻补给点”

落叶堆的糖果掉落频率被明确调高了。这一条看着不起眼，实际上对上桌体验影响很大——节日期间满地乱翻落叶堆的收益变稳了，跑图路上顺手一扫，糖果、小玩意就进兜里了。配合本次修复的“落叶堆可以用动作键清扫”，你终于不用对着那堆叶子反复点鼠标、怀疑是不是自己网络卡了。

### 🐚 岩石龙虾：终于不用在酸雨里掉血了

这条是我个人最想给科雷鼓掌的。此前岩石龙虾在月岛洞窟、远古档案这类会下酸雨的区域里，是会被酸雨持续伤害的——你辛辛苦苦养大的龙虾军团，带下去一趟就跟下饺子似地掉血。现在修复后，这些区域里的龙虾正常免疫酸雨。对于喜欢带龙虾当移动护甲、靠它们扛伤害的玩家来说，这属于实打实的体验升级。

### 🧹 其他几处“小而烦”的修复

- **Mac 运行问题**：Mac 玩家此前启动或运行异常的情况得到处理，苹果党可以正常回坑了。
- **附魔女巫扫帚动画**：客户端开启预测时使用扫帚会出现动画错乱，现已修正，飞起来终于不抽帧了。
- **皮肤显示**：国王科学机器被烧毁后不再变成“隐形建筑”；蝎子手杖镶入宝石后在背包里也能正常显示，不再凭空消失吓人一跳。

### 🛠 给模组作者的一段说明

专用服务器新增了两个可选的启动参数，用来放宽模组对 cluster 存档目录的读写权限：

- `-allow_persistentstorage_read_sandbox_escape`
- `-allow_persistentstorage_write_sandbox_escape`

懂行的都明白，这类“沙盒逃逸”开关是把双刃剑：方便了需要读写存档的复杂模组，但也意味着模组代码能碰到更多东西。公共服务器、尤其是订阅了大量来源不明模组的服主，开之前最好先过一遍模组清单，别为了图省事把家门钥匙随手递出去。

## 💡 玩家实操与上手建议

1. **更新方式**：Steam 库中《饥荒联机版》会自动拉取热修，客户端重启一次即可，无需重新开档，老存档继续用。
2. **节日刷糖路线**：优先走落叶堆密集的地图区域，边走边用动作键清扫，效率比手动点选高不少；顺路去猪王那里交个任务，运气好能白嫖一波糖果，运气不好就多一枚南瓜炸弹。
3. **南瓜炸弹处理法**：拿到后单独放一格背包，回基地第一时间存进远离火源的箱子，或者直接拿去对付成群的猎犬与蜘蛛——恶作剧道具用在敌人身上，那叫物尽其用。
4. **龙虾队配置**：修复后可以放心把岩石龙虾带到月岛洞窟和远古档案，让它们顶在前面吸收仇恨，你在后面安心采集与输出。
5. **服务器管理员**：那两个启动参数请按需开启，不要默认常开；开启后建议定期备份 cluster 文件夹，避免模组写坏存档。
6. **联机避坑**：动画修复只影响客户端表现，如果你还遇到扫帚动作错位，先检查模组是否覆盖了相关动画资源。

## ❓ 常见问题 FAQ

**Q1：这次热修需要重新开档吗？会影响现有存档吗？**
A：不需要。Hotfix 760178 属于兼容性修复，现有世界可以直接继续玩。唯一需要留意的是，如果你在修复前刚好把国王科学机器皮肤烧成了隐形状态，读档后建议重新放置一次建筑确认显示正常。

**Q2：猪王给的南瓜炸弹是活动限定道具吗？会不会占背包？**
A：它属于节日活动玩法的一部分，只能在活动期间通过猪王获得。体积上占一格物品栏，建议不要随身携带太多，避免关键时刻背包塞满捡不了资源。

**Q3：我的专用服务器想启用模组读写存档目录，要注意什么？**
A：按需添加 `-allow_persistentstorage_read_sandbox_escape` 与 `-allow_persistentstorage_write_sandbox_escape` 参数即可，但只对信任的模组开启。启用前务必备份 cluster 目录，公共服尤其要谨慎，避免模组误写导致存档损坏。
