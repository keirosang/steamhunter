# Project Exhibitionist v1.0.1 更新速报：脱困按钮上线，内存占用再瘦身

> 主理人碎碎念：这次补丁没有花里胡哨的大饼，全是“救命”和“顺手”的硬活儿。对一款还在持续打磨的作品来说，能把卡加载、穿模、超宽屏 UI 这些磨人的小妖精按在地上摩擦，比什么都实在。

## 🎯 核心看点速览

- **新增“Unstuck”脱困按钮**：暂停菜单一键把角色从卡墙、掉图里捞出来；但在家、监狱和加载过程中不可用。
- **鼠标反转拆成横纵两项**：终于可以只反 Y 轴，不用连 X 轴一起遭殃。
- **角色预设可编辑**：自定义角色栏新增铅笔图标的 Edit 按钮，捏脸党狂喜。
- **补上特定模式下的走路/跑步脚步声**：不再“静音滑步”。
- **修复新开局卡 32% 加载**：这个最要命，先更先享受。
- **内存占用下降**：启动与加载阶段减负，低内存机器少一点闪退焦虑。
- **超宽屏/高分辨率 UI 修复**：32:9 下角色预览不再挡按钮，1080p 以上动作轮盘也能正常点选。

## 📌 重点深度解析

### 1. 卡加载与掉图：这次真给了一颗后悔药

新版本重点修了“新开局卡在 32%”的加载问题，同时给暂停菜单加了 **Unstuck** 按钮。以后不小心卡进地铁维护门、掉出地图，或者被场景几何体“抱住”，不用再含泪重开。注意：在家、监狱和加载过程中这个按钮不可用，别在安全区里疯狂点它。

### 2. 显示适配：超宽屏玩家终于被看见

32:9 显示器上角色预览挡菜单按钮、1080p 以上动作/表情/姿势轮盘选不中，这些“高分辨率专属 Bug”都修了。再加上小地图拖拽与标记放置修复，带鱼屏玩家这次可以少摔一次鼠标。

### 3. 内存与加载优化：低配机的续命包

官方把启动和加载阶段的内存占用压了一截，衣柜与 Collection 预览加载也做了优化，城市流式加载的任务分配更均匀。虽然不能说“老爷机瞬间满血”，但至少读图时后台挂个浏览器、语音软件，压力会小一些。

### 4. 一堆“小但烦人”的修复

地铁维护门补碰撞、地铁未发车时再次上车的行为修正、住宅区隐形垃圾桶、地图打开时无限冲刺体力、扭蛋/照相亭被抓时的镜头与操作异常、Stimulation 任务需求描述缺失、段位要求距离四舍五入误导、物品拖拽加右键产生重复图标、Collection 车辆使用计数、小地图与脚步音走错音量通道、特定角色肤色与 Ciel 肤色不匹配、服装动作与 Hide & Flash 道具之间的姿势过渡、奶牛配饰的可用性与保存、设置滑块重开后显示错误数值……看得出来，制作组在认真扫屋角。

### 5. 多语言与美术小更新

12 种支持语言的文本同步更新，领口 ID 照片会匹配当前 Ciel 预设，人体彩绘笔图标、保龄球馆招牌和商场海报也换了新装。

## 💡 玩家实操与上手建议

- **先更新再进游戏**：Steam 库中右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性，能解决大部分更新后的玄学问题。
- **低内存机器**：进游戏前关掉多余后台；Windows 虚拟内存别关；画质预设先稳一手，等官方后续性能补丁再拉满。
- **超宽屏玩家**：更新后先检查 UI 缩放与轮盘点击区域，如果还有遮挡，截图带分辨率反馈给官方。
- **遇到卡死**：优先按 Esc 找 **Unstuck**；如果按钮不可用，再读最近存档，别硬钻地图缝隙。
- **反馈 Bug 的正确姿势**：附上 PC 配置、系统版本、复现步骤和截图/录像，官方 Discord 有专门板块，信息越全修得越快。
- **购买建议**：本作定位成人向，题材与内容接受度请先自行确认；本次是免费补丁，已入库玩家直接更新即可，无需额外购买 DLC。

## ❓ 常见问题 FAQ

**Q1：更新后我的存档会没吗？**

A：正常更新不会主动清存档，但大版本前后建议手动备份存档文件夹。若遇到读档异常，先验证游戏文件完整性，再查看是否有云同步冲突。

**Q2：Unstuck 按钮为什么是灰的/点不了？**

A：官方设定在家、监狱以及加载过程中不可用，这是为了防止在安全区域或读图阶段误触。只有正常探索场景卡住时才建议使用。

**Q3：低配电脑这次优化明显吗？**

A：启动与加载内存占用确实下降了，但性能优化是长期工程。建议先关后台、保留虚拟内存，并用最低/中画质测试；如果仍闪退，把配置和日志反馈给官方。
